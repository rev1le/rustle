## О проекте
Rustle — это кроссплатформенная утилита на Rust для интеллектуального анализа дискового пространства, которая классифицирует файлы как «нужные» или «мусор» с помощью многоуровневого ИИ-агента (правила → эвристики → локальная LLM). Инструмент обеспечивает полную приватность данных, так как обработка происходит локально без отправки файлов в облако, и адаптируется под конкретные потребности пользователей через контекстные профили (например, для разработчиков или фотографов). В отличие от статических анализаторов вроде WinDirStat, Rustle предлагает интерактивный TUI-интерфейс, систему геймификации здоровья диска и безопасную очистку с возможностью восстановления файлов. Проект сочетает высокую скорость сканирования благодаря параллелизму на Rust с умной автоматизацией, помогая пользователям поддерживать порядок в файловой системе без страха потерять важные данные.

## Правила кода
Для написания SHOULD использовать скилл `polytail`.
Тесты для функционального кода выносить в отдельный файл-пакет.
Если связанность в файле нарушается - значит нужно разбивать файл на несколько пакетов.
Не писать комментарии под каждым куском кода, писать MUST временного решения или с неявными моментами.

## Commit Message Convention

```
<type>: <short summary>

Where <type> =>
feat:     new functionality
fix:      bug fix
docs:     comments / README / AGENTS.md
style:    formatting, no logic change
refactor: restructure without behaviour change
test:     add or update tests
chore:    deps, CI, config
```
